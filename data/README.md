# Data Assets

This directory stores reference data and generated outputs required by the CRISPR pipeline. Large binaries are ignored from Git; populate the folders locally before running the stack.

## Layout
- `genomes/`: Genome FASTA files, annotations, and CRISPRitz indices (ignored by Git).
- `CFD_scoring_matrix/`: CFD mismatch and PAM scoring pickles. Bundle placeholder files are tracked to document expected paths.
- `PAM/`: PAM definition text files used by CRISPRitz.
- `results/`: Runtime job outputs generated by Celery tasks (ignored by Git).

## Setup notes
Follow the top-level `README.md` instructions to download genomes, build CRISPRitz indices, and configure environment variables pointing to the assets you store here.
